# VIDNOVA Mini App v1.2 — три блоки та вбудована анкета

## Вміст
- `index.html` — три тематичні підрозділи статусу S, 10 публікацій, консультації.
- `assets/` — надані оригінальні обкладинки.
- `worker.js` — опціональний Cloudflare Worker для автоматичного отримання заявок у приватний чат адміністратора.

## Консультації
- Безкоштовне первинне звернення (не повна консультація).
- Персональна консультація — **60 CHF / 45 хв** (українська, німецька та англійська версії інтерфейсу).
- Вбудована анкета: ім’я, контакт, тема, тип, питання, згода.

## Важливо про відправлення
За замовчуванням `CONSULTATION_ENDPOINT=''`: кнопка створює лист `mailto:` в поштовому застосунку відвідувача. **Користувач повинен сам відправити лист**. Успішність надсилання не підтверджується застосунком.

Для автоматичної відправки: (1) розгорнути `worker.js` у Cloudflare Workers; (2) встановити секрети `BOT_TOKEN` і `ADMIN_CHAT_ID` і змінну `ALLOWED_ORIGIN=https://tarasenkoolesia-maker.github.io`; (3) у `index.html` вписати HTTPS URL Worker до `CONSULTATION_ENDPOINT`; (4) протестувати надсилання реальної заявки всередині Telegram. Токен бота **ніколи** не додавати в `index.html` або до GitHub. Worker перевіряє Telegram initData та повертає успіх лише після підтвердженої доставки API Telegram. Додайте rate limiting Cloudflare перед публічним запуском.

## Розгортання
Перед завантаженням зробити резервну копію поточного GitHub репозиторію `tarasenkoolesia-maker/vidnova-miniapp`. Завантажити **вміст папки** (index.html, assets та, за потреби, worker.js) у корінь репозиторію. Без налаштування Worker форма працює лише через відкриття поштового клієнта.

## Конфіденційність
Для реального збору заявок узгодити й опублікувати політику конфіденційності з реквізитами контролера даних, строком зберігання та контактами. Не запитувати чутливі медичні чи паспортні дані в цій анкеті.
