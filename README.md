# Українці в Швейцарії × VIDNOVA — Telegram Mini App v1.0

Односторінковий двомовний застосунок українською та англійською для мобільного Telegram і браузера.

## Перевірені посилання
- Канал: https://t.me/UkrainianSwitzerland
- Чат: https://t.me/UkrainiansInSwitzerlandChat

## Важливо до публікації
- У `index.html` в об'єкті `window.VIDNOVA_DATA` параметр `consultationUrl` **тимчасово веде на канал**, бо прямий контакт для бронювання не надано.
- Тематичні картки поки ведуть на канал загалом; замініть ці адреси посиланнями на тематичні пости або добірки.
- Додаток не збирає персональних даних, не містить платіжної інтеграції, не здійснює запис автоматично.
- Telegram SDK завантажується з офіційної адреси `https://telegram.org/js/telegram-web-app.js`; для офлайн/регіонально обмежених умов можна розмістити перевірену копію локально й змінити шлях.

## GitHub Pages
1. Створіть **public** репозиторій `vidnova-miniapp` у GitHub.
2. Завантажте `index.html` у корінь репозиторію.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Посилання буде `https://USERNAME.github.io/vidnova-miniapp/`.
5. Перевірте в мобільному браузері і в Telegram.

## Telegram BotFather
1. Створіть бота через `/newbot`. Не передавайте нікому токен.
2. `/newapp` → оберіть бота → заповніть назву, опис, обкладинку, Web App URL (адреса GitHub Pages) і short name.
3. BotFather надасть посилання вигляду `https://t.me/BOT_USERNAME/SHORT_NAME`.
4. Протестуйте на iOS і Android переходи на канал і чат.
5. Розмістіть посилання в закріпленому повідомленні каналу (або через довірений постинг-сервіс з URL-кнопкою).
